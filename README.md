# NEON BLACKJACK ⚡ PVP

Real-time PVP Blackjack game with neon cyberpunk aesthetics.

## Features
- 🃏 Real-time 1v1 Blackjack PVP
- ⚡ Neon cyberpunk UI with glow effects
- 🎮 Room-based matchmaking (create/join with code)
- 📱 Mobile responsive
- 🔄 Multiple rounds with win tracking
- ✨ Animated card dealing

## How to Play
1. Enter your name
2. Create a room or join with a code
3. Share the room code with your opponent
4. Both players press READY
5. Take turns: HIT or STAND
6. Closest to 21 wins!

## Tech Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion

## Deploy
```bash
npm install
npm run build
npm start
```

Deploy to Vercel:
```bash
npx vercel --prod
```
